GitHub Actions

Integrate security scan checks directly using our custom pipeline action.

- name: ShieldOps Security Gate
  uses: shieldops/security-action@v1
  with:
    client_id: ${{ secrets.SHIELDOPS_CLIENT_ID }}
    client_secret: ${{ secrets.SHIELDOPS_CLIENT_SECRET }}

GitLab CI

Add security scans as a gating stage within your `.gitlab-ci.yml` build runs.

shieldops-scan:
  stage: test
  image: shieldops/runner-cli:latest
  script:
    - shieldops scan --fail-on-critical true
  only:
    - merge_requests

Jenkins Pipeline

Integrate within declarative pipelines using the ShieldOps shared steps module.

stage('Security Scan') {
    steps {
        shieldopsScan(
            clientId: 'SHIELDOPS_CLIENT_ID',
            credentialsId: 'shieldops-auth-token',
            failBuild: true
        )
    }
}
